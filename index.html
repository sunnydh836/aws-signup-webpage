Step 2

Create Your AWS Builder Account

Open the official signup link and create your AWS Builder account. Read the instructions below carefully before you click.

Important Signup Instructions

  1. Use a unique username and alias name for every new signup. Do not reuse the same username or alias name.
  2. When signing up using a mobile phone, open the signup page in Chrome Desktop Site mode.
    Chrome on mobile → Tap three-dot menu → Select “Desktop site”
  3. After completing the signup, open your AWS Builder profile and copy the exact username and alias name shown there.
  4. Paste the copied username and alias name into the Google Form.
  5. Complete the AWS Builder signup before filling out the Google Form.
  6. Enter all details carefully because incorrect username or alias information may cause the submission to be rejected.
